交互与系统方案

核心交互

  • 锁定单据后扫码输入自动获得焦点；扫码枪发送 Enter 时默认增加 1 件。
  • 成功后清空条码并回焦；商品行置顶并短暂高亮，收货件数同步更新。
  • 异常上报通过工作台统一入口打开弹窗，不占用扫码和表格空间。
  • 少货提交后扣减可收数量并进入待处理状态；多货单独记录，不改变正常收货数量。

字段与计算口径

商品列表沿用现有字段：imageUrl、productName、seriesName、skuCode、upcCode、attributes、shipmentQuantity、canReceiptQuantity、quantity。

已收货总件数建议按 Σ receiptQuantity + Σ quantity 展示；当前接口已返回 receiptQuantity，本次扫码 quantity 由页面实时累加，无需新增后端字段。

扫码枪兼容

后台 Web 当前通过 input 键盘事件接收扫码枪数据，适配常见 USB / 蓝牙 HID 扫码枪。安卓仓库另有 Zebra Scanner SDK + StateFlow 封装，可作为未来 POS App 收货能力的设备接入基础，本次后台页面无需耦合安卓实现。
